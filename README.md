# 🌿 OPGK Lab

A collection of free browser games for your spare moments.
すきま時間に気軽に遊べる、無料のブラウザゲーム集です。

🔗 **Play now / 今すぐ遊ぶ:** https://opgklab.github.io/opgk-lab-games/

## About

OPGK Lab is a small collection of simple, free-to-play browser games.
No installation, no login, no ads — just open the link and play.

OPGK Labは、シンプルで無料で遊べるブラウザゲームを集めた個人制作サイトです。
インストール不要・ログイン不要、リンクを開くだけで遊べます。

- Free / 無料
- No login required / ログイン不要
- No advertisements / 広告なし
- No competition or ranking / 競争・ランキングなし

## Games

Games are grouped into three categories:
ゲームは3つのカテゴリに分かれています。

- 🧩 **Brain & Puzzle** — puzzles and logic games / パズル・思考系ゲーム
- ⚡ **Quick Reaction** — fast-paced reflex games / 反射神経を試すゲーム
- 🧸 **Casual & Relaxing** — laid-back, no-rush games / のんびり遊べるゲーム

New games are added from time to time.
See the full list on the [game page](https://opgklab.github.io/opgk-lab-games/).

新しいゲームはマイペースに追加しています。
最新の一覧は[ゲームページ](https://opgklab.github.io/opgk-lab-games/)でご確認ください。

## Technology

- HTML / CSS / JavaScript (no frameworks)
- GitHub Pages

All games run directly in the browser — no build step, no backend.
すべてのゲームはブラウザ上で直接動作します（ビルドやサーバー不要）。
